# Artefatos do Projeto – DashVendas

Esta pasta reúne todos os artefatos produzidos durante o desenvolvimento do projeto DashVendas.

## Estrutura

| Pasta | Descrição |
|--------|-----------|
| **DiagramaAtividades** | Diagramas de Atividades do sistema. |
| **DiagramaDeArquitetura** | Diagramas da arquitetura lógica e física da aplicação. |
| **DiagramaDeClasses** | Diagramas de Classes do domínio do sistema. |
| **DiagramaDeSequenciaProjeto** | Diagramas de Sequência de Projeto (nível de implementação). |
| **DiagramaEntidadeRelacionamento** | Modelo Entidade-Relacionamento (DER). |
| **DiagramaImplantação** | Diagramas de Implantação da arquitetura física. |
| **DiagramasDeCasosDeUso** | Diagramas de Casos de Uso. |
| **DiagramasDeComunicação** | Diagramas de Comunicação. |
| **DiagramasDeSequencia** | Diagramas de Sequência do Sistema (DSS). |
| **DocumentoProjetoAntigos** | Versões anteriores da documentação do projeto. |
| **Dtos** | Diagramas e documentos relacionados aos DTOs utilizados na aplicação. |
| **telas** | Capturas de tela do sistema desenvolvido. |
| **Videos** | Vídeos de apresentação e demonstração do projeto. |
| **Wireframes** | Protótipos e wireframes das interfaces. |
